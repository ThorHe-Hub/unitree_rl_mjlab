## 1. 公共条件

model_12000，Unitree-G1-Flat，fixed_body，friction=0.8（未设 contact_friction）。PID 0.91/0/0.01，vx=0.5（V、G 例外）。
陀螺：BMI088 档 σg=1.728e-3 rad/s/步，ε_b=0.02 rad/s，bias_rrw=0。参考：σa=0.05 rad，1 Hz（R 例外），无丢包。trace schema v6。

**两种陀螺信号（variant）**，同种子配对：
- `point`：估计器用 50 Hz 点采样 ω_z（历史行为，含步态锁相混叠）。
- `interval`：估计器用相邻姿态反推的区间平均 ω_z（delta-angle），加同一份零偏与噪声。
策略观测在两种 variant 下相同，都是点采样扣零偏。

**臂**（q_b 由开发集离线网格按各自最优预先选定，两种 variant 相同）：

| 臂 | 反馈 | q_b | τ |
|---|---|---:|---:|
| B* | integrated | 1e-4 | ∞ |
| C* | fusion_heading | 1e-16 | 0 |
| S1 | fusion_offset_smoothed | 1e-16 | 1.0 s |
| C8 | fusion_heading | 1e-8 | 0（仅 V） |

τ=1 s 的依据：离线扫描中，MEMS 档所有参考率 × σa 组合的平滑窗口下界最大值为 1.0 s，精度上界最小值为 2.0 s。

## 3. 指标

- 估计误差 = feedback_heading − 真值航向（展开、以首步为 0），RMS。窗口：N/R/G 为 [30,60) s；O 为中断前 [10,20)、中断中 [20,50)、恢复后 [50,60)、其后 [60,90)；V 为 [10,30)、[60,90)。
- 最大反馈跳变：[5 s, 末尾) 内 feedback_heading 单步变化绝对值的最大值；O 另算恢复跳变 [50 s−1 步, 52 s)。
- 指令跳变：cmd_vyaw 同口径。tilt：[5 s, 末尾) 的 p99 与最大值。
- G：e = mean(ω_z,点 − ψ̇)，分解为采样项 mean(ω_z,点 − ω_z,区间) 与欧拉项 mean(ω_z,区间 − ψ̇)，区间 [5 s, 末尾)。

## 6. 次要假设（描述性，不校正）

- **S1 variant 效应**：interval 下 C* 与 S1 的误差比 point 下略小（离线 −0.03°），S1 的最大跳变显著更小（0.19° → 0.04°，因为点采样引起的反馈抖动消失）。
- **V1**：point 下 [60,90) 误差 C8 < C*（离线 1.072 vs 1.627）。
- **V2**：interval 下 [60,90) 误差 C* < C8（离线 0.624 vs 1.018），方向与 V1 **相反**。这是"变速需要更大 q_b"来自点采样混叠的直接检验。
- **V3**：interval 下 C* 在变速后误差不上升（[60,90) 不大于 [10,30)）；point 下上升。
- **R1**：0.5 Hz 与 2 Hz 下，S1 误差比 C* 高不超过 0.1°，最大跳变更小（离线：0.5 Hz 2.33 → 0.19°，2 Hz 1.10 → 0.19°，point）。
- **R2**：C* 误差 ≈ √(0.2² + (0.765/√f)²)，与离线预言差 < 20%。
- **G1**：复现开发集 G：6 档步速都 |e − (采样项 + 欧拉项)| < 1e-5；变号出现在 0.5 与 0.65 之间；采样项在 ≥5 档中占主导；用区间平均角速度积分时 60 s 末端误差 < 0.5°。
